### 🤖 AI Voice Assistant

An experimental project focused on building a modular voice assistant.

Architecture:

```text
User
  ↓
Microphone
  ↓
ESP32 / Raspberry Pi
  ↓
Server
  ↓
Speech-to-Text
  ↓
AI / LLM
  ↓
Intent / Automation
  ↓
Arduino / ESP32 / IoT
  ↓
Physical Devices
```

The goal is to integrate **voice commands, artificial intelligence and IoT devices** while keeping heavier AI processing on an external server.
